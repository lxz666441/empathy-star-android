# 共情星隐私政策（测试版草案）

公开源码整理日期：2026-11-03；本文件仍是测试版草案，不代表已完成上线审核。

ML Kit 披露依据（2026-09-29 核对）：[Google ML Kit Terms & Privacy](https://developers.google.com/ml-kit/terms)；[Google Play Data disclosure guide for ML Kit](https://developers.google.com/ml-kit/android-data-disclosure)。发布前仍需按实际依赖版本和商店表单复核。

本文件是个人测试版的隐私披露草案，不是可供商店审核的公开政策页面。公开分发前，需要发布为可访问网页，补齐运营者/联系渠道，并按实际部署模型服务和分发平台复核。

## 应用处理的数据

- 1.45 的语句知识点和建议回复共用一次主动模型分析：原文概念与释义、整句解释及三条回复仅保留在内存，本地校验术语须匹配所选原文及完整词边界；点击已返回的知识点只展开释义，不再联网。模型请求失败仅保存固定错误码，不保存原始响应、异常正文或聊天。
- Debug 的“共情星兼容读取（测试）”是共情星自身的实验服务入口，复用相同的数据边界，不代表 Google 官方应用，不声明残障专用无障碍工具身份，也不进入 Release。它用于兼容已验证微信版本的节点暴露行为；不能保证其他设备或微信版本仍可用。

- 无障碍服务：仅对用户分别授权、未暂停且位于前台的微信或QQ读取当前可见节点文字和位置。只对结构已验证的聊天页处理消息，为方向可靠的对方非敏感文字定位入口；不按情绪关键词筛选普通消息。开启读取本身不调用模型或上传内容。微信适配当前仍可能返回空树，授权不代表一定可读。
- QQ群聊：有独立默认关闭授权，一期只提供当前可见消息多选总结，不提供群内逐消息星标或填入。显示名仅从已验证昵称槽取得，不代表唯一身份，不采集成员列表。
- 多选总结：默认不选择消息；用户选择后还需同意本次上传以及当前平台模型授权，才向已配置服务发送所选文字、方向及已取得的显示名。最多30条、12000字符；不自动收集完整历史、全部未读或未选上下文。
- 手动 OCR：仅在 Android 14+ 且用户于符合条件的聊天页主动点击“识别”后，截取当前屏幕并在设备内存中识别。截图和 OCR 文字不写入应用文件，也不会发送给 Google；用户取消或离开微信时不提交模型。OCR 使用 Google ML Kit，其 SDK 会通过 HTTPS 向 Google 发送设备信息（如厂商、型号、系统版本和可用 ML 硬件）、应用包名与版本、每次安装的标识符，以及性能/使用诊断数据（如延迟、图像格式/分辨率、输入输出大小、功能版本、调用事件和错误码）。根据 Google 当前披露，这些数据用于诊断和使用分析，不向第三方转移；ML Kit 也可能联系 Google 获取缺陷修复、模型或硬件兼容信息。发布时需按实际 SDK 版本复核此披露并在目标商店的数据安全声明中申报。
- 模型请求：须同时满足用户已勾选独立的模型数据授权、配置了 API Key 并主动点击一个消息星标（或在 OCR 候选中选中文字后点击“分析这段”）。点击星标会立即开始请求，无需再按卡片内的“分析”按钮。无障碍分析将星标对应消息单独作为目标，并可能附带它之前最多 8 条当前屏幕可见文字；不发送所选消息之后的文字。OCR 分析只发送用户选中的候选文字。请求使用用户配置的 HTTPS 模型端点，可能产生服务商费用。
- 请求取消：关闭分析卡片、切换离开聊天或服务退出时，应用会使请求失效并断开仍在进行的网络连接；如果内容已经到达模型服务端，应用无法撤回，服务端处理和保留仍受其政策约束。
- 设置：模型端点、模型名和 API Key 密文保存在应用私有设置；API Key 使用 Android Keystore 加密。应用备份已关闭。诊断偏好仅包含服务状态、时间和去内容化计数/结果类别，不保存聊天正文。

## 第三方处理

模型请求会发送至用户自行配置的模型服务提供方。该提供方对请求内容的处理、日志和保留期限由其隐私政策与账户设置决定；共情星无法控制或保证提供方不留存。用户应阅读对应政策并避免发送敏感聊天信息。模型端点必须使用 HTTPS。Google ML Kit 的图像/文字输入和识别结果在设备本机处理，不发送到 Google 服务器；SDK 可能另行传输 OCR 性能/使用诊断指标，具体数据类别和用途见上文及 Google 官方隐私说明。

## 用户控制与安全边界

微信与QQ的读取和模型授权分别保存，另有独立暂停设置。未同意当前平台模型数据授权时，即使本机保存有 API Key，也不会发送聊天内容。应用不会自动发送微信或QQ消息，也不会将建议覆盖到已有草稿。

## 联系方式与发布状态

本测试版未配置公开运营者信息或联系地址，也没有可访问的隐私政策网页，因此尚不具备公开分发所需的完整隐私材料。发布前须补齐这些信息并按目标平台要求完成数据安全披露。
